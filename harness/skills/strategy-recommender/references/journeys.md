# 用户问法与下一步

这是按意图分流的参考，不是固定问卷。找策略首屏从收益目标、可承受回撤、投资方向、用钱时间进入；用户可任选一点或直接自由输入。多个意图并存时先完成用户当前明确请求，再解决阻塞下一步的条件；不要由关键词直接指定策略。

| 用户怎么说 | 先做什么 | 必要时只追问这一点 | 接下来产出 |
| --- | --- | --- | --- |
| 不知道选什么/新手 | 区分长期积累、已有钱、已有持仓、先学习 | 你是每月有结余，还是已经有一笔钱？ | 一个明确方向或待确认候选 |
| 每月 2,000 元，想长期积累 | 记录预算和投入方式，不再问金额 | 这笔钱最早什么时候会用？ | 预算内候选；信号触发投入不能冒充固定月投 |
| 有 10 万，怎么投 | 区分可投资部分和近期支出 | 其中有多少需要近期留用？ | 可投入部分的方案；不默认一次投满 |
| 怕亏/最多能接受亏 5% | 区分承受意愿与保证不亏 | 这是可接受的波动，还是必须保证的底线？ | 风险不符则无候选；不把回测回撤当保证 |
| 少操作/没时间盯盘 | 解释检查频率和交易频率不同 | 你希望少看行情，还是限制实际操作次数？ | 规则与频次证据；不凭“趋势”标签断言低频 |
| 这只基金适合什么策略 | 查明标的身份及目录支持范围 | 如基金不明确，问名称或代码 | 支持该标的的候选；基金相同不代表策略相同 |
| 看看我现在的持仓怎么调整 | 先检查本会话账户权限 | 未授权：选择授权入口或手动描述 | 针对持仓问题的策略候选；不是自动全仓替换 |
| 哪个收益最高/能年赚 15% 吗 | 解释口径和目标不是承诺 | 若要个性化：最晚何时要用钱？ | 同口径历史比较或可行性讨论，不保证达标 |
| 高收益但一点都不能亏 | 明确条件冲突，不生成“满足”的候选 | 不能亏是硬要求，还是愿意接受一定波动？ | 保持硬要求则停止推荐不符策略 |
| 这个怎么运行/RSI 是什么 | 直接解释该规则的条件、动作、代价 | 通常不用先问预算 | 所选策略引用与查看回测入口 |
| 看回测/比较前两个 | 解析当前对象及结果口径 | 对象不明确才问；要新回测时确认样本 | 可比证据和差异；不强迫完成画像 |
| 按我每月 2,000 元试试 | 核对当前选择及预算到参数的映射 | 缺标的或关键参数时问对应缺项 | 参数草稿或确定性回测结果 |
| 改成每两周一次 | 查参数合同与年度预算影响 | 现有预算固定还是每次金额固定？ | 支持范围内修改，或者明确当前不支持 |
| 就用这个/保存一下 | “就用这个”先区分研究选择与保存请求 | 未确认关键配置时展示草稿再确认 | 可追溯配置版本；不自动买入 |
| 都不适合我 | 定位最关键的不满足条件 | 哪项不能接受：波动、操作还是资金安排？ | 修改筛选/零候选；不强推或偷偷造策略 |
| 用 RSI 20/70 做买卖 | 核对现有策略是否完整支持此语义 | 未明确时问指标周期/动作之一 | 参数变体或待开发的自建规则草稿 |

## 阶段间怎么衔接

### 需求 → 候选

用户：“每月 2,000 元，三年不用，最好少操作。”

保留三个条件；查询当前目录；下一问聚焦承受波动，不能再问“你准备投多久”。此时可解释哪些规则限制投入次数，但不能把“每周期最多三次”说成“每月只交易一次”，也不能默认可承受纯权益风险。

### 候选 → 理解 → 对比

用户：“为什么是它？”引用那一套的规则、用户明确条件和一项不匹配处。用户：“比较前两个。”使用本次候选顺序，不改成收益榜前两名；历史区间不一致时先说明，不能直接比较累计涨幅。

### 对比 → 个性化回测

用户：“第二个，按我的金额跑一下。”明确第二个对象；目录里的 `amount` 是单次投入，不是月预算。若允许一个月三次且还有加速倍数，要核算上限；不能直接设为 2,000 元并称月预算仍为 2,000 元。支持参数不足以落实月预算时明确说明，不伪造新参数。

### 回测 → 保存

用户：“可以，保存。”如果前文只有默认样本展示，先明确保存的基金、参数与名称；如果用户已确认完整草稿可直接保存配置。返回实际工具 ID/版本，说明是否仍有计划环节待用户完成。回测被阻塞则保留规则选择，提示缺失数据，不说计划已验证。

### 从已有策略转自建

用户：“我想用 RSI14，低于 20 买，大于 70 卖，每月最多 2,000。”先对照现有合同：若只支持低吸和目标止盈，指出卖出规则不同，不能把目标止盈改名成 RSI 卖出。整理指标定义/周期、阈值、动作、预算约束和仍缺的仓位/执行细节。当前仅形成自建草稿，不调用任意代码执行或假装回测。

## 复核场景

| 输入/情境 | 应观察到的行为 | 不应出现 |
| --- | --- | --- |
| 已说金额和期限 | 仅询问决定候选的剩余条件 | 从头重复问卷 |
| 拒绝提供亏损意愿 | 可先学习或看待确认候选 | 阻止一切继续操作/推测偏好 |
| 明天要用且不能损失 | 说明目录策略不满足，不推荐波动策略 | 把某次回测正收益当无风险 |
| 无账户权限谈持仓 | 提供手动描述路径 | 查询或复述未授权账户数据 |
| 回测缺数据/失败 | 保存已有判断，指出缺项与下一步 | 补造曲线、换指标不告知 |
| “想定制，少操作” | 在已上线策略及支持参数中找 | 新造移动均线或 RSI 策略 |
| 明确新卖出信号 | 说明引擎支持边界并整理草稿 | 调用旧参数却声称新算法已生效 |
| 恢复旧候选 | 重新核对目录与结果日期 | 继续推荐已不可用对象 |
