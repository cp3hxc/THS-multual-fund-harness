# SUVI 可组合页面与多端展示

## 当前原型

- 对话开始后使用主内容区；策略详情或对比作为当前任务对象，用户可返回原工作区继续操作。
- “我的页面”默认打开已保存的可操作页面。用户点击“编辑页面”后可修改名称、增删模块、用上移/下移调整顺序，完成后回到页面。桌面和手机预览共用同一份配置与渲染组件。
- 页面模块中的策略可进入策略详情，计划、持仓和行情模块可进入对应工作区。收益数据只来自账户接口；没有实时行情源时明确展示待接入状态。
- 当前配置保存在本机 `localStorage`。分享稿只导出标题、模块 ID 和 schema 版本，不导出账户、持仓、策略计划或对话数据。
- 社区发布服务和跨设备同步尚未接入；页面不会把本机预览误写成已公开分享。

## 正式落地的数据模型

页面模板与用户数据分离。模板是可公开的 JSON，包含 `schemaVersion`、`templateId`、`title`、`blocks`、`layout`、`createdBy`、`publishedVersion`；模块只引用经过审核的组件 ID 与允许的展示参数。用户的计划、持仓、账户权限、通知记录留在受保护的业务服务中，模板不承载这些数据。桌面与移动端使用同一个模板解析器与模块数据契约，按屏宽决定列数、顺序和交互密度。

## 用户操作路径

1. 用户调整模块、字段，或与 SUVI 讨论形成页面草稿。未来 AI 修改只产生可查看的变更提议；用户确认后保存新版本。
2. 桌面、手机预览使用同一份配置。手机端优先显示计划状态、最新事件和主要操作；复杂回测表格进入详情页。
3. 分享时生成公开模板快照，自动排除用户数据。发布前展示模板标题、模块、数据权限与移动端预览；社区服务审核后返回模板 ID 与版本。
4. 他人“使用这个模板”只复制布局和公开策略引用，不复制作者的计划、账户和聊天。数据由使用者自己的权限按需加载。

## 服务端能力清单

- 页面配置：`GET/PUT /api/me/pages/{id}`，账号级存储、版本号、冲突检测、跨设备同步。
- 移动端：同一账号授权后读取配置与业务对象；返回数据包含来源、数据时间、权限状态。不能把桌面 `127.0.0.1` 当作手机数据源。
- 社区：模板草稿、发布、审核、版本、撤回、举报、收藏和复制。公开快照必须经过白名单校验，不能携带账户号码、持仓金额、私人目标、聊天记录或 API Key。
- 自定义策略：用户编排受支持的策略规则、参数和风险边界，先校验规则再回测；策略版本与计划版本独立保存。AI 生成规则仍须用户确认，并保留修改前后差异。

## 不应混淆的状态

- “保存页面”只保存布局；不会开启交易。
- “保存策略计划”与“开启条件监控”分开；触发信号不自动下单。
- “社区模板”是页面与公开规则，不是作者真实收益展示。历史回测、个人账户收益和市场行情分别标注。
