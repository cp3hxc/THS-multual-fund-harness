# 看行情实施与数据映射

依据：用户提供的《看行情-完整设计文档-v1.0》。本文件记录当前客户端实际可运行的能力和未接入的能力，不把页面占位视为完成。

## 启动

在项目目录运行 `npm start`，进入客户端左侧「看行情」。独立本地服务由桌面客户端启动。市场页面配置保存在当前设备的 `localStorage`；自选基金沿用服务端本机状态。

## 当前实现

| 能力 | 状态 | 数据或行为 |
| --- | --- | --- |
| 大盘指数快照 | 已接入 | `GET /api/market/indices`，腾讯行情；逐项展示状态与时间，30 秒服务端缓存。 |
| 自选基金 | 已接入本机清单 | 本机 `GET /api/bootstrap`、`POST /api/watchlist`；与账户持仓分开。自选列表不再展示公告列。 |
| 同花顺账户自选同步 | 等待接口 | 当前爱基金账户连接只覆盖持仓和交易，未提供账户自选读取接口；客户端同步入口明确告知缺口，不显示假成功。 |
| 已披露单位净值 | 已接入 | `GET /api/market/fund-detail?code=` 代理同花顺基金 `GET /quotation/fund_detail/v2/getNavData` 的 `unit`；展示净值日期。 |
| 基金公告 | 已接入 | 同一个本机接口代理同花顺基金 `GET /interface/net/pubnote2/0_{code}_1_5`；展示标题、发布日期、类型与原文链接，不推断公告影响。 |
| 基金基础资料 | 已接入 | 同一个本机接口代理同花顺基金 `GET /quotation/fund_detail/v2/base/{code}`；展示基金类型、风险等级与成立日期。 |
| 基金复权净值与阶段表现 | 已接入 | 现有 `GET /api/fund/nav`，扶摇复权净值；使用完整时间序列计算区间变化及历史峰值回撤。与已披露单位净值分开展示。 |
| 指数详情和三项对比 | 部分实现 | 当前只有可核验的当日快照；不同数据时刻不直接排名。历史曲线和分时数据未接入。 |
| 首页及详情模板 | 已实现本机版 | 首页 4 种布局、详情 5 种布局；页面社区从顶部导航移到首页内容底部。布局调整主要由 AI 对话生成草稿，保存前可撤销。 |
| AI 页面编辑 | 已实现草稿协议 | AI 根据当前组件 ID 生成 `MARKET_PAGE_DRAFT`；客户端校验版本与组件白名单，用户保存后生效。需要已配置可用模型服务。 |
| 自定义历史回撤指标 | 已实现本机版 | 指标定义含方法、时间窗口、输入、缺失规则与版本；由真实复权净值重复计算，可插入基金详情。 |
| 重仓当日贡献参考 | 定义可保存，计算未接入 | 披露持仓资产权重与股票当日行情缺失，页面显示不可计算；不会输出猜测值。 |
| 实时基金估值 | 字段已展示，数据源未接入 | 自选列表有「实时估值」列；没有可核验的盘中估值时显示「—」和缺失原因，不拿指数涨跌或正式净值填充。 |
| 页面社区 | 本机演示版 | 官方模板与本机作品可预览、复制；分享包只含结构和方法，不含账户金额、凭证、聊天与提醒。跨用户发布、更新及审核服务未接入。 |
| 提醒 | 本机有限版 | 指数跌幅规则保存在设备本地，仅在客户端打开且刷新行情时检查；无后台任务或系统通知。 |
| 移动端 | 响应式页面 | 同一组件布局在窄宽度改为单列；尚无独立移动客户端或跨设备同步。 |

## 数据约束

- 指数涨跌、基金复权净值、已披露单位净值和个人账户收益各自独立，不互相代替。
- 接口失败显示不可用状态；正式数据模式没有演示数据兜底。
- 基金详情可查看真实公告原文；自选首页不展示公告看板，也不根据公告标题推断影响。
- 现有指数快照和复权净值数据分别来自腾讯行情与扶摇，尚未达到文档提出的「金融数据统一来自同花顺金融数据 API」目标。单位净值和公告已映射同花顺基金接口。统一数据源需要确认鉴权、字段、时效与授权范围后迁移。
- 页面配置目前是单机 `localStorage`，不能声称跨设备同步；发布和提醒需要服务端持久化与权限体系。

## 后续接入顺序

1. 核验并接入同花顺指数分时及历史行情接口，完成指数区间图和同口径对比。
2. 接入披露持仓、费率及关联事件，补全基金类型适配和公告影响分析。
3. 建立受控计算服务，输入披露持仓资产权重与股票行情，确定性计算重仓贡献与用户自定义估值，附报告期、覆盖率及缺失处理。
4. 将页面、组件、指标和社区作品迁移到用户账号服务；发布前做数据依赖、隐私与代码权限校验。
5. 将提醒迁移到后台任务和通知服务，保存触发快照、送达状态与失败重试记录。
